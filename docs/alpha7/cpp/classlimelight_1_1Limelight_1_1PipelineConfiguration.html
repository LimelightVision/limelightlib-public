Detailed Description

An immutable, validated pipeline configuration override.

It holds the contents of a .vpr file. Create it one time during robot initialization. All file IO and size validation happen at that time. Then publish it at any time with SetPipelineConfigurationOverride(const PipelineConfiguration&).

// RobotInit
auto aiming = limelight::Limelight::PipelineConfiguration::FromDeployFolder("aiming");
auto intake = limelight::Limelight::PipelineConfiguration::FromDeployFolder("intake");
// mid-match
camera.SetPipelineConfigurationOverride(aiming);
